Introdução e Comandos Básicos do Portugol — Parte 3

Objetivo da Aula: Aprender a utilizar estruturas condicionais no Portugol para que os programas possam tomar decisões.

Introdução

Até agora aprendemos:

  • comandos básicos;
  • variáveis;
  • entrada de dados;
  • operações matemáticas.

Porém, muitos programas precisam tomar decisões. Eles podem, por exemplo, precisar verificar idade, senha, analisar notas, comparar valores, etc. Para isso utilizamos estruturas condicionais.

O que são estruturas condicionais?

Estruturas condicionais permitem que o programa escolha ações diferentes dependendo da situação. Exemplo:

  • se a pessoa for maior de idade;
  • então mostrar uma mensagem específica.

Na programação, isso ajuda o computador a “decidir” qual caminho seguir.

O comando SE

O comando "se" é usado para verificar condições. 


                se condicao entao
                
                comandos
                
                fimse

A condição é colocada entre o "se" e "entao". Assim, se a condição for verdadeira, o programa executará os comandos que estão entre "entao" e "fimse". Alguns editores mostram esse bloco com espaços no início das linhas para facilitar a organização visual do código.

Exemplo simples 


                algoritmo "idade"
                
                var 
                idade: inteiro 
                
                inicio 
                
                escreva("Digite sua idade: ") 
                leia(idade) 
                
                se idade >= 18 entao 
                
                escreva("Você é maior de idade") 
                
                fimse 
                
                fimalgoritmo

O programa:

  • pede a idade;
  • guarda a informação;
  • verifica a condição;
  • mostra a mensagem se a condição for verdadeira.

Operadores de comparação

Os operadores de comparação ajudam a verificar condições.

Operador Significado
= igual
<> diferente
> maior
< menor
>= maior ou igual
<= menor ou igual

O comando SENAO

O comando "senao" é usado quando queremos mostrar outro resultado caso a condição seja falsa. 


            se condicao entao
            
            comandos 
            
            senao 
            
            comandos
            
            fimse

Exemplo com SENAO 


            algoritmo "aprovacao"
            
            var 
            nota: real 
            
            inicio 
            
            escreva("Digite sua nota: ") 
            leia(nota) 
            
            se nota >= 7 entao
            escreva("Aprovado") 
            
            senao
            escreva("Reprovado") 
            
            fimse 
            
            fimalgoritmo

Como funciona a condição?

Neste exemplo:

  • se a nota for maior ou igual a 7;
  • o programa mostra “Aprovado”.

Caso contrário:

  • mostra “Reprovado”.

A importância das condições

As estruturas condicionais são muito importantes porque permitem criar programas mais inteligentes. Elas são utilizadas em:

  • sistemas;
  • aplicativos;
  • jogos;
  • sites;
  • cadastros;
  • login de usuários.
  • e em sistemas mais sutís, como divisão por zero.

Organização do código

Durante a programação é importante:

  • manter o código organizado;
  • usar nomes simples, porém auto-explicativos;
  • evitar excesso de informações.

Isso facilita a leitura, manutenção. acessibilidade e aprendizado.

Portugol e Aprendizagem

As estruturas condicionais ajudam no desenvolvimento do raciocínio lógico. Aprender esses conceitos facilita o estudo de outras linguagens de programação no futuro.

Resumo da Aula

Nesta aula aprendemos:

  • o que são estruturas condicionais;
  • comando "se";
  • comando "senao";
  • operadores de comparação;
  • tomada de decisão nos programas.

As condições permitem que os programas analisem situações e executem diferentes ações.
