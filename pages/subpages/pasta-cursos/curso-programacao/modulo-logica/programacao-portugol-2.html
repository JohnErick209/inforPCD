Introdução e Comandos Básicos do Portugol — Parte 2

Objetivo da Aula: Aprender sobre variáveis, entrada de dados e operações básicas utilizando Portugol.

Na aula anterior aprendemos:

  • comando "escreva";
  • comando "escreval";
  • comentários

Agora vamos aprender como os programas podem:

  • guardar informações;
  • receber dados do usuário;
  • realizar cálculos simples.

O que são variáveis?

Variáveis são espaços usados para armazenar informações. Elas funcionam como “caixas” que guardam dados. Exemplos:

  • nome;
  • idade;
  • número;
  • nota.

Na programação, as variáveis ajudam o programa a lembrar informações.

Declarando variáveis

Antes de usar variáveis, precisamos criá-las. No Portugol usamos a palavra var. Exemplo: 


                var
                nome: caractere
                idade: inteiro

Tipos de variáveis

Cada variável possui um tipo, isso é, guarda um valor em específico.

inteiro

Guarda números inteiros (10, 25, 100).

real

Guarda números com decimais. (5.5, 7.8, 10.2).

caractere

Guarda letras, palavras e textos. ("Maria", "computador", "A").

O comando LEIA

O comando "leia" permite receber dados do usuário. Exemplo: 


                algoritmo "nome"
                
                var
                nome: caractere
                
                inicio 
                
                escreva("Digite seu nome: ")
                leia(nome)
                
                escreva("Olá, ", nome)
                
                fimalgoritmo

Nesse exemplo:

  1. o programa pede o nome;
  2. o usuário digita;
  3. a informação é armazenada;
  4. depois o nome aparece na tela.

Operações matemáticas

O Portugol também pode realizar cálculos.

  • Soma: +
  • Subtração: -
  • Mutiplicação: *
  • Divisão: /

Exemplo de soma 


                algoritmo "soma"
                
                var 
                n1: inteiro 
                n2: inteiro 
                resultado: inteiro 
                
                inicio 
                
                escreva("Digite o primeiro número: ") 
                leia(n1) 
                
                escreva("Digite o segundo número: ") 
                leia(n2) 
                
                resultado <- n1 + n2 
                
                escreva("Resultado: ", resultado)
                
                fimalgoritmo

Explicando o símbolo "<-"

O símbolo "<-" significa “recebe”. 

 resultado <- n1 + n2

Isso quer dizer que a variável "resultado" vai guardar o valor da soma.

A importância das variáveis

As variáveis são fundamentais na programação pois elas permitem:

  • armazenar informações;
  • realizar cálculos;
  • criar sistemas;
  • desenvolver programas mais avançados.

Portugol e Aprendizagem

O Portugol ajuda iniciantes a aprender lógica, organização, entrada e saida de dados, cálculos, estrutura de programação, entre outros. Esses conhecimentos serão importantes para aprender outras linguagens no futuro.

Lembre-se: As variáveis ajudam programas a guardar e utilizar informações.
