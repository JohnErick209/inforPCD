Introdução à Programação e Lógica de Programação

Objetivo da aula:

Introdução

A programação está presente em muitas tecnologias do dia a dia, nos celulares, em aplicativoss, em jogos, sites, eletrodomésticos, etc. Essas tecnologias, tecnicamente chamadas de computadores conseguem realizar tarefas porque recebem instruções criadas por programadores. Essas instruções são chamadas de códigos.

O que é programação?

Programação é o processo de criar comandos para o computador executar tarefas. Os computadores não pensam como os seres humanos, eles apenas seguem instruções. Exemplo: Quando uma pessoa abre um aplicativo, existe uma programação dizendo ao computador o que deve acontecer.

O que é lógica de programação?

Lógica de programação é a forma organizada de resolver problemas usando passos. Antes de escrever códigos, o programador precisa pensar:

  • no problema;
  • na solução;
  • na ordem correta das ações.

A lógica ajuda o computador a entender exatamente o que deve fazer.

Exemplo de lógica no dia a dia

Muitas atividades usam lógica. Exemplo: fazer um sanduíche.

  1. pegar o pão;
  2. colocar o recheio;
  3. fechar o pão;
  4. servir.

Existe uma sequência correta de ações. Na programação acontece a mesma coisa.

O que é algoritmo?

Um algoritmo é uma sequência de passos para resolver um problema. Os algoritmos estão presentes em:

  • receitas;
  • manuais;
  • instruções;
  • programas de computador.

exemplos de algoritmo:

Escovar os dentes

  1. pegar a escova;
  2. colocar pasta;
  3. escovar os dentes;
  4. enxaguar.

Como os computadores entendem comandos?

Os computadores utilizam linguagens de programação. Essas linguagens permitem que os programadores escrevam instruções. Exemplos de linguagens:

  • C;
  • Python;
  • JavaScript;
  • Java.

Cada linguagem possui regras próprias.

O que é um programa?

Um programa é um conjunto de instruções criado para realizar tarefas. Exemplos:

  • calculadora;
  • navegador;
  • editor de texto;
  • aplicativo de mensagens.

Todos esses programas foram criados com programação.

A importancia da programação

A programação´é muito importante atualmente. Com ela, é posssivel automatizar tarefas, controlar sistemas, criar tecnologias acessíveis, etc. Muitas empresas procuram profissionais de programação.

Programação e acessibilidade

A programação pode ajudar pessoas com deficiência por meio de leitores de tela, comandos por voz, tradução em Libras, etc. Programadores também podem criar sistemas acessíveis para incluir mais pessoas na tecnolgia.

Resumo da aula

Nesta aula, aprendemos sobre o que é programação e a lógica de programação, o que é algoritmo, como os computadores executam comandos e a importancia da programação no mercado de trabalho. A lógica de programação é a base para aprender qualquer linguagem de programação.
